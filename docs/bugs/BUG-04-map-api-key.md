# BUG-04 — Карта вакансий пустая: Yandex Maps JS API — Invalid API key

- **Приоритет:** 🔴 блокер экрана (карта не работает вовсе)
- **Экран:** таб «Карта» (`/map`) — у обеих ролей

## Шаги воспроизведения

1. Открыть `/map` на проде (или локально) под любой ролью.
2. Посмотреть на контейнер карты и консоль браузера.

## Фактический результат

- Контейнер карты пустой (серый прямоугольник с обводкой), тайлов и
  маркеров нет. Под контейнером видно только `10 вакансий ·
  Яндекс.Карты`.
- Консоль: `(Yandex Maps JS API): Invalid API key`.
- Данные при этом приходят: `GET /vacancies/map` → 200, маркеры
  добавляются в `map.geoObjects`, но тайлы не грузятся.

## Причина

`frontend/src/routes/map.tsx` грузит скрипт без ключа:

```ts
script.src = 'https://api-maps.yandex.ru/2.1/?lang=ru_RU'
```

Яндекс требует API-ключ для JS API 2.1 — без `apikey` карта не
инициализируется (раньше работало без ключа, поэтому регрессия внешняя,
а не следствие редизайна).

## Ожидаемый результат

Карта рендерит тайлы и метки активных вакансий; клик по метке открывает
балун (title, компания ✓, город, зарплата).

## Как чинить (предложение)

1. Получить ключ в Кабинете разработчика Яндекса (JS API + HTTP Геокодер
   не нужен, только JS API), лимитов бесплатного тарифа для хакатона
   достаточно.
2. Пробросить ключ через env: `VITE_YANDEX_MAPS_API_KEY` → при создании
   скрипта `?apikey=${key}&lang=ru_RU`; в docker/CI добавить переменную
   на build-этапе фронта.
3. До появления ключа показывать на экране карты понятное состояние
   «Карта временно недоступна» вместо пустого контейнера.

## Фикс

- Получен ключ JavaScript API (кабинет yandex.ru/maps-api), залит в
  GitHub Secret `VITE_YANDEX_MAPS_API_KEY`; проброшен через
  `ARG` в `frontend/Dockerfile` и `build-args` в ci-cd.yml.
- Карта мигрирована с JS API 2.1 на 3.0 (`ymaps3`, тёмная тема,
  HTML-маркеры, клик → карточка вакансии); координаты в 3.0 — [lng, lat].
- Без ключа в бандле показывается понятная ошибка вместо пустого контейнера.
- Локальная разработка: `frontend/.env.local` (в .gitignore).
