# BUG-02 — Кривое тире в диапазоне зарплаты

- **Приоритет:** 🟡 косметика/UX
- **Экран:** рекрутер → «Новая вакансия» → секция «Условия» → «Оклад»
- **Связанное:** карточки вакансий/приглашений (`formatSalary`) — там тире
  соответствует макету

## Шаги воспроизведения

1. Открыть `/company/vacancies/new`, секция «Условия», строка «Оклад».

## Фактический результат

Строка выглядит как `от        –        до   ₽`: тире «повисает» в
середине строки между двумя разнесёнными инпутами (оба прижаты вправо,
`max-width: 90px`), при пустых полях чтение диапазона разваливается.
С заполненными значениями тире не «приклеено» к числам и съезжает в
зависимости от ширины введённого текста.

В макете (Figma, экран «Новая вакансия») оклад — одно целостное значение
у правого края: `250 000 – 350 000 ₽` (en dash с неразрывными пробелами).

## Ожидаемый результат

Диапазон читается как одно значение у правого края строки, тире стоит
вплотную к числам: `250 000 – 350 000 ₽`. В пустом состоянии —
аккуратный placeholder (например, `—`), а не разрозненные `от/до`.

## Причина

`frontend/src/routes/recruiter/vacancy-new.tsx` (и аналогично
`resume.tsx`): два независимых `<input type=number>` + отдельный спан с
тире + спан с `₽`, выровненные через flex `justify-content:
space-between` родительской строки — визуальная целостность диапазона
не гарантируется.

## Как чинить (предложение)

Обернуть пару инпутов в один контейнер, прижатый вправо
(`margin-left: auto`, `gap: 2px`), тире сделать `en dash` c
неразрывными пробелами (`\u2013`, `white-space: nowrap`); плейсхолдеры
`от`/`до` убрать или заменить на единый `—`.
