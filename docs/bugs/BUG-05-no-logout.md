# BUG-05 — Нет кнопки разлогина / смены роли

- **Приоритет:** 🟠 UX-блокер для демо и тестирования
- **Экран:** все экраны приложения

## Шаги воспроизведения

1. Войти в мини-апп (демо-вход или через MAX), выбрать роль.
2. Попробовать выйти из аккаунта или сменить роль (например, с
   рекрутера на кандидата).

## Фактический результат

Кнопки/пункта «Выйти» нет ни на одном экране. Единственный путь
сбросить сессию — вручную почистить `localStorage` (`max_token`,
`max_user`) в devtools: `clearSession()` вызывается только автоматически
при 401 (`frontend/src/api/client.ts`). Сменить роль через UI тоже
нельзя: `/onboarding` показывается лишь пока роль не выбрана
(`Guard allowNoRole`).

Для демо это блокер: нельзя показать вторую роль на одном устройстве
(рекрутер ↔ кандидат), не залезая в devtools.

## Ожидаемый результат

- Кнопка «Выйти» (иконка/пункт в меню), по нажатию: `clearSession()` →
  редирект на `/` (логин). В MAX-сессии выход возвращает к авто-логину
  под тем же юзером — поэтому рядом полезен и пункт «Сменить роль»,
  ведущий на `/onboarding` (`POST /me/role` доступен и повторно).
- В демо-режиме (вне MAX) после выхода можно войти под другим
  демо-пользователем и ролью.

## Как чинить (предложение)

- Добавить в `TabBar`/хедер иконку-меню или отдельный экран «Профиль» с
  пунктами «Сменить роль» и «Выйти».
- «Выйти»: `clearSession(); navigate('/')`.
- «Сменить роль»: `navigate('/onboarding')` + на онбординге показать
  текущую роль; смена — существующий `setRole`.
