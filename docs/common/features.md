# Фичи продукта

## Основные

### 1. Реверс найм (ядро продукта)

Кандидат загружает резюме, компании публикуют вакансии. Система
сопоставляет их и даёт рекрутеру инструменты выбора кандидатов.

Подфичи:

| # | Подфича | Суть |
|---|---------|------|
| 1.1 | Еженедельное уведомление об актуальности подбора | Раз в неделю кандидат получает в MAX вопрос: актуален ли ещё подбор вакансии для него. Ответ обновляет активность резюме в выдаче |
| 1.2 | TTL на ответ рекрутера | Компания сама настраивает срок, за который рекрутер обязан отреагировать на кандидата. Просрочка фиксируется и показывается кандидату |
| 1.3 | Сортировка кандидатов по приоритету | Скоринг соответствия резюме вакансии: алгоритм (ключевые слова, опыт, график/город) + AI-оценка. Рекрутер видит кандидатов от лучших к остальным |
| 1.4 | Обычный список кандидатов | Классическая табличная выдача: фильтры, поиск, карточка кандидата |
| 1.5 | Свайп-подбор кандидатов | Лента кандидатов в формате дейтинг-приложения/рилсов: свайп вправо — пригласить, влево — пропустить. Для рекрутера |

### 2. Верификация профиля компании в MAX

Компания может/обязана верифицировать свой профиль в MAX. Верифицированным
компаниям — бейдж доверия в карточках вакансий. Цель — безопасность
кандидатов: меньше фейковых «работодателей».

### 3. Реферальная система через deeplink в MAX

Каждый пользователь получает персональную ссылку (`?startapp=...`,
`start_param` в MAX Bridge). Переход по ней фиксирует реферера —
награда за привлечённых пользователей/отклики.
