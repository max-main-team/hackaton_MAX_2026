# План работ

## Скоуп на хакатон (MVP)

Готовим вертикальный срез фичи «Реверс найм» + демо внутри MAX.

### Этап 0 — каркас ✅

- [x] Монорепозиторий: Go (Echo, pgxpool) + React (Vite, TS)
- [x] Postgres в docker-compose, миграции при старте
- [x] `POST /auth` по initData (пока без проверки подписи), upsert пользователя
- [x] MAX Bridge на фронте: `window.WebApp`, `getInitData()`

### Этап 1 — домен и безопасность

Бек:
- [ ] Проверка подписи `initData` (`MAX_APP_SECRET_KEY`), выдача JWT
- [ ] Модель роли: кандидат / рекрутер (выбор при первом входе)
- [ ] Модель компании: название, описание, флаг верификации
- [ ] Резюме кандидата: должность, навыки, опыт, город, график, статус «активен»
- [ ] Вакансия: компания, описание, требования, город/удалёнка, TTL отклика

Фронт:
- [ ] Экран выбора роли после логина
- [ ] Кандидат: карточка резюме (создание/редактирование)
- [ ] Рекрутер: привязка к компании, форма вакансии

### Этап 2 — матчинг и взаимодействие

Бек:
- [ ] Базовый скоринг резюме↔вакансия на Postgres (ключевые слова, город, график)
- [ ] Эндпоинты выдачи: список кандидатов по вакансии + свайп-лента
- [ ] Свайпы рекрутера: приглашение / пропуск; матч по реакции кандидата
- [ ] TTL: статус «ждёт ответа N часов», просрочка → уведомление кандидату
- [ ] Отклик кандидата на приглашение (интересен / не интересен)

Фронт:
- [ ] Рекрутер: свайп-лента кандидатов (фича 1.5) + список с фильтрами (1.4)
- [ ] Рекрутер: настройка TTL вакансии (1.2)
- [ ] Кандидат: входящие приглашения, дедлайн ответа, статус просрочки
- [ ] Бейдж «верифицирована» у компаний (заглушка-флаг в MVP)

### Этап 3 — уведомления и полировка демо

Бек:
- [ ] Еженедельный опросник кандидату «актуален ли подбор?» — рассылка
      через Bot API MAX + cron (фича 1.1)
- [ ] Сидовые данные для демо (компании, вакансии, резюме)

Фронт:
- [ ] Экран матча, хаптика через `HapticFeedback`
- [ ] Полировка под тему MAX (colorScheme), стабилизация

## Открытые вопросы

- Как кандидат отвечает рекрутеру: в чате MAX (бот-прокси) или внутри мини-аппа?
- Еженедельный опрос: сообщение от бота с кнопками или пуш в мини-апп?
- TTL: кто видит статистику просрочек и влияет ли она на рейтинг компании?
- Что именно верифицируем: бота/канал компании, организацию в MAX, домен?
