# T-27 — AI-скоринг (LLM-оценка соответствия)

- **Статус:** ❄️ заблокирован: нужен LLM API-ключ (провайдер на выбор команды)
- **Спека:** docs/common/features.md (фича 1.3, AI-часть)

## Что сделать (когда появится ключ)

- `internal/scoring/ai.go`: запрос к LLM — сравнить JSON резюме и вакансии,
  получить score 0..100 и комментарий; кешировать результат в БД
  (`resume_scores`), чтобы не дёргать LLM на каждый запрос.
- `AI_*` env: ключ, модель, лимиты. Без ключа — только алгоритмический скоринг.
- Подмешать AI-оценку в итоговый score (вес согласовать).

## Примечание

Базовый алгоритмический скоринг реализован в T-08 (веса + токены навыков).
AI — надстройка поверх, фолбэк уже работает.
