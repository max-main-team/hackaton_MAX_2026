# T-28 — Логика бота в MAX (чат)

- **Статус:** ✅
- **Спека:** docs/max/bot-api.md (GET /updates, POST /messages, POST /answers)
- **Зависимости:** T-12 (общий MAX_BOT_TOKEN)

## Что сделать

- `internal/worker/bot.go`: long polling `GET /updates` (marker + time=30).
- `message_created` → приветствие + inline-клавиатура:
  кнопка `open_app` («Открыть мини-приложение») и callback «Как это работает».
- `message_callback` → `POST /answers` с пояснением.
- `bot_started` (нажатие «Начать») → приветствие юзеру через `POST /messages?user_id=`.
- Анти-спам: отвечать только на сообщения свежее 2 минут (без спама при рестартах).
- Воркер стартует из main.go вместе с survey-воркером.

## ⚠️ Блокер (платформа, не код)

Нажатие «Начать» в MAX не создаёт диалог с ботом. Точная причина
установлена через Playwright MCP (консоль веб-клиента): сервер MAX
отвечает на отправку `0x40 error.user.blocked.send — User is
restricted` (аккаунт ограничен платформой), поэтому диалог не
создаётся, `dialog.not.found` и событие `bot_started` в `/updates`
не приходит. Не ошибка сертификатов: веб-клиент работает, ошибка —
бизнес-код сервера MAX. Код бота и токен исправны
(токен 200 на `/me`, поллинг работает). Проверить на
business.max.ru: статус бота (модерация/публикация/активация).
После активации бота на платформе флоу должен заработать без
изменений кода. Проверено через Playwright MCP: клиент шлёт
«Начать», платформа событие не генерирует.
