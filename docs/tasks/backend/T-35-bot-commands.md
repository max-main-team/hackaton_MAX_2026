# T-35 — Полная логика бота: команды, ответы, статус

- **Статус:** ✅
- **Спека:** docs/max/bot-api.md
- **Зависимости:** T-28 ✅

## Что сделано

- Регистрация команд бота при старте: `PATCH /me/commands`
  (start / help / status), не критично при ошибке.
- Роутер сообщений `routeCommand`: `/start`, `/help` (+«помощь», «как…»),
  `/status` (+«статус»), остальное → подсказка с кнопками.
- `/status` — персональные данные из БД (users.id = MAX user id):
  кандидат — резюме (активно/пауза) и число приглашений без ответа;
  рекрутер — компания, верификация, квота инвайтов; незнакомый юзер —
  приглашение в мини-апп.
- Колбэк «Как это работает» — развёрнутое объяснение реверс-найма.
- Сырой лог поллинга понижен до Debug.

## Тесты

- Юнит: роутер команд, тексты статусов (кандидат/рекрутер/новый),
  форма клавиатуры, состав команд.
- Интеграционный: `fetchUserStatus` с реальной БД (skip без БД).
