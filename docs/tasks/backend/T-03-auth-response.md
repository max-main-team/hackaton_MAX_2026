# T-03 — Новый ответ `/auth` `{token, user}`

- **Статус:** ⬜
- **Спека:** `docs/backend/spec-auth.md` (раздел 3)
- **Зависимости:** T-02
- **Разблокирует:** T-05; **делается одним коммитом с T-13 (фронт)**

## Что сделать

- `internal/handler/auth.go`: ParseInitData → Verify (если секрет задан) →
  upsert пользователя → `Issue` → ответ `{"token": "...", "user": {...}}`.
- Ошибки: протухший auth_date / невалидная подпись → 401.
- Пользователь в ответе включает `role` (после T-04; до неё — `null`).

## Критерии приёмки

- [ ] curl `/auth` (dev, без секрета) → 200, в ответе token и user.
- [ ] Фронт из T-13 логинится этим ответом end-to-end.
- [ ] `go build ./... && go vet ./... && gofmt -l .` — чисто.
