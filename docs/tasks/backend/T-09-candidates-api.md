# T-09 — Выдача кандидатов по вакансии

- **Статус:** ✅
- **Спека:** `docs/backend/spec-api.md` (раздел «Матчинг: выдача кандидатов»)
- **Зависимости:** T-07, T-08
- **Разблокирует:** T-10, T-17 (лента/список)

## Что сделать

- Миграция 000003 НЕ нужна здесь — только чтение `resumes` + `users`.
- `GET /vacancies/{id}/candidates?mode=list|feed&limit&offset`:
  членство → 403; вакансия неактивна → 409.
- Кандидаты: `role='candidate'`, активное резюме, нет recruiter_actions
  по этой вакансии (появятся в T-10; до неё — просто без фильтра).
- Скоринг каждой пары вакансия↔резюме (`scoring.Score`), сортировка
  score desc; `list` — limit/offset + total, `feed` — без пагинации.
- Ответ: `{"items": [{score, breakdown, user, resume}], "total": N}`
  по контракту из спеки.

## Критерии приёмки

- [ ] Рекрутер не из компании → 403; неактивная вакансия → 409.
- [ ] Кандидат с подходящими навыками выше неподходящего.
- [ ] `go build ./... && go vet ./... && gofmt -l .` — чисто.
