## Как вести задачу

1. **Постановка:** копируешь шаблон ниже в `backend/T-XX-имя.md` или
   `frontend/T-XX-имя.md`, заполняешь, добавляешь строку в README-индекс
   папки и в `docs/common/status.md`.
2. **Работа:** статус → 🚧 (в работе) в трёх местах (файл, индекс, status).
3. **Сдача:** критерии приёмки выполнены → статус → ✅, коммит с кодом
   и изменением статусов; документация `как есть` обновляется тем же
   коммитом.

## Легенда статусов

| Метка | Значение |
|-------|----------|
| ⬜     | не начато |
| 🚧     | в работе |
| ✅     | готово (критерии приёмки выполнены) |
| ❄️     | отложено / заморожено |

## Правила параллельной работы

- Бек и фронт договорились о контракте → работают параллельно; контракт
  менять только через правку спеки + уведомление другой стороны.
- Стыковка бек↔фронт: T-03 и T-13 делаются одним коммитом (смена формата
  `/auth`), остальное независимо.
- Номера T-XX не переиспользуем; новая задача = новый номер (продолжить
  нумерацию T-21+).
