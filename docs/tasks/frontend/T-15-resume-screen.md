# T-15 — Экран резюме кандидата

- **Статус:** ⬜
- **Спека:** `docs/frontend/spec-ui.md` (раздел «Резюме»)
- **Зависимости:** T-14
- **Разблокирует:** T-17 (лента видит резюме)

## Что сделать

- `routes/candidate/resume.tsx`: форма — title, skills (теги/строка),
  experience_months, about, city, schedule (селект full/part/remote/hybrid).
- Загрузка: `GET /my/resume` → 404 = пустая форма, иначе предзаполнение.
- Сохранение: `PUT /my/resume`; состояния loading / error / saved
  (короткий тост или подпись «Сохранено»).
- Валидация на клиенте дублирует бек: title непустой, schedule из списка.

## Критерии приёмки

- [ ] Создание и повторное редактирование работают (данные сохраняются).
- [ ] Невалидная форма не отправляется, ошибка бека показывается.
- [ ] `npm run build && npm run lint` — чисто.
