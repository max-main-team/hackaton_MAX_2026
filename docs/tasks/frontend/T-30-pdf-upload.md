# T-30 — Загрузка резюме PDF (фронт)

- **Статус:** ⬜
- **Спека:** `docs/backend/spec-pdf-parse.md`, `docs/backend/spec-api.md` (POST /my/resume/parse)
- **Зависимости:** T-15 (бек: T-29)
- **Разблокирует:** полный флоу онбординга через PDF

## Что сделать

- Экран резюме: кнопка «Загрузить PDF» (input file, accept=.pdf, ≤10МБ).
- Извлечение текста в браузере: `pdfjs-dist` (ленивый импорт, worker через
  `?url`), склейка текста страниц, лимит ≤30 000 символов.
- `POST /my/resume/parse` → предзаполнение формы ответом
  (`resume.*` + `links` из JSON) + показать `ai_comment`.
- Состояния: извлечение текста → парсинг AI → готово (правь и сохраняй);
  ошибки: PDF без текстового слоя («заполни вручную»), AI-ошибка, лимиты.
- После правок юзер жмёт «Сохранить резюме» (PUT) — резюме активируется.

## Критерии приёмки

- [ ] PDF с текстовым слоем (кириллица) → поля формы предзаполнены.
- [ ] «Сохранить резюме» → данные в БД, `source='file_parse'`.
- [ ] Скан без текстового слоя → понятный fallback на ручное заполнение.
- [ ] `npm run build && npm run lint` — чисто.
