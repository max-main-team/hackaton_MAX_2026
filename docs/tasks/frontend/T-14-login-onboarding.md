# T-14 — Логин и онбординг

- **Статус:** ⬜
- **Спека:** `docs/frontend/spec-ui.md` (разделы «Логин», «Онбординг»), `docs/common/stage-1.md` (шаг 9)
- **Зависимости:** T-13
- **Разблокирует:** T-15, T-16

## Что сделать

- `routes/login.tsx`: при монтировании `api.auth(getInitData())` → токен
  → редирект: `role=null` → `/onboarding`, candidate → `/resume`,
  recruiter → `/company`. Вне MAX (`initData === ''`) — кнопка
  «Демо-вход» (тот же POST с пустой строкой) либо текст
  «Открой мини-апп через MAX».
- `routes/onboarding.tsx`: две карточки «Я кандидат»/«Я рекрутер» →
  `POST /me/role` → редирект.
- Гарды: без токена → `/`; без роли → `/onboarding`; чужой раздел →
  редирект на домашний экран роли.
- `webApp.ready()`/`expand()` при монтировании.

## Критерии приёмки

- [ ] Полный проход: логин → роль → домашний экран роли.
- [ ] Повторный вход с сохранённым токеном пропускает логин.
- [ ] `npm run build && npm run lint` — чисто.
