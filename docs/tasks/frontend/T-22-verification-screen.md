# T-22 — Верификация компании (фронт)

- **Статус:** ✅
- **Спека:** docs/tasks/backend/T-21-company-verification.md, docs/frontend/spec-ui.md
- **Зависимости:** T-16 (бек: T-21)

## Что сделать

- В карточке компании (не verified): блок «Верификация в MAX» —
  поле для токена бота компании + кнопка «Верифицировать» →
  `POST /companies/{id}/verify`.
- Успех → `Badge` verified в карточке компании и в вакансиях.
- Ошибка токена → понятный текст «Токен недействителен».

## Критерии приёмки

- [ ] Валидный токен бота → verified, бейдж отображается.
- [ ] Невалидный токен → ошибка показана, состояние не ломается.
- [ ] `npm run build && npm run lint` — чисто.
