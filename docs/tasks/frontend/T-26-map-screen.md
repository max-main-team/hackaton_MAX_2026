# T-26 — Карта вакансий (фронт)

- **Статус:** ⬜
- **Спека:** docs/tasks/backend/T-25-map-api.md
- **Зависимости:** T-14 (бек: T-25)

## Что сделать

- `npm i leaflet react-leaflet` (OSM-тайлы, без API-ключей).
- Страница «Карта»: `GET /vacancies/map` → маркеры вакансий;
  клик по маркеру → карточка (title, зарплата, компания, verified-бейдж).
- Центр карты — СПб (59.9386, 30.3141), зум 11.
- Пустое состояние: «Пока нет вакансий на карте».

## Критерии приёмки

- [ ] Маркеры seeded-вакансий (СПб) отображаются.
- [ ] Карточка по клику открывается.
- [ ] `npm run build && npm run lint` — чисто.
