# Подключение мини-приложения в MAX

Источник: https://dev.max.ru/docs/webapps/introduction

## Главное

- Мини-приложение работает **только внутри чат-бота** — автономно не существует.
- Платформа: https://business.max.ru/self — доступна юрлицам, ИП и
  самозанятым, резидентам РФ (после верификации профиля).
- Мини-апп — обычный сайт: HTML/JS/CSS по **https** (http не работает).

## Шаги подключения

1. Создать профиль организации/ИП/самозанятого на платформе, верифицировать.
2. Создать чат-бота (раздел «Чат-боты»), пройти модерацию.
3. Хостинг для статики: любой https-хостинг (VK Cloud, GitHub Pages,
   Yandex Cloud и т.п.).
4. Платформа → Чат-боты → выбрать бота → **⋮ → Настройки** → вставить URL
   мини-приложения → выбрать вид кнопки (Открыть / Старт / Играть / без
   названия) → Сохранить.

Требования к URL: ≤1024 символов, только `https://`, латиница/цифры/точка/
дефис, без пробелов, валидный.

После привязки в чате с ботом появляется кнопка запуска мини-аппа.

## Диплинки

Формат запуска мини-аппа:

```
https://max.ru/<botName>?startapp=<payload>
```

- `payload` — до 512 символов, допустимы `[A-Za-z0-9_-]`; при нарушении —
  молча удаляется из ссылки.
- В приложении payload доступен как `window.WebApp.initDataUnsafe.start_param`.
- Не передавать в payload конфиденциальные данные в открытом виде —
  только одноразовые токены/идентификаторы.

Примеры сценариев: `startapp=feedback_rest123`, `startapp=promo123`,
`startapp=ref_user123_campaign_sale` (рефералка — фича 3).

Диплинк шеринга: `https://max.ru/:share?text=<url-encoded текст>` —
открывает нативный экран «Отправить в MAX».

## Для нашего проекта

- Реферальная ссылка: `https://max.ru/<botName>?startapp=ref_<userId>` —
  в аппе читаем `start_param`, фиксируем реферера.
- Еженедельный опрос (T-12): сообщение от бота с кнопкой
  `open_app`/диплинком `?startapp=confirm` → в аппе экран подтверждения.
- Изменение URL/кнопки/удаление — там же в настройках бота на платформе.
