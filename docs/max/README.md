# Документация MAX (выжимка для проекта)

Дистиллированная копия официальной документации https://dev.max.ru —
достаточная для работы без открытия сайта. Источники указаны в каждом файле;
при спорных моментах приоритет у оригинала.

## Файлы

| Файл | Содержание | Когда нужен |
|------|------------|-------------|
| [mini-app-setup.md](./mini-app-setup.md) | Платформа, бот, привязка мини-аппа, диплинки `startapp`, `start_param` | Релиз, рефералка (фича 3) |

## Ключевые факты (важно!)

1. **Мини-приложение живёт внутри бота** — отдельно от бота не существует.
   URL мини-аппа привязывается к боту на платформе business.max.ru.
2. **Секрет для валидации initData — токен бота**, никакого отдельного
   «ключа приложения» нет: `secret_key = HMAC-SHA256("WebAppData", BOT_TOKEN)`.
   У нас это env `MAX_BOT_TOKEN` (см. `init-data.md`).
3. Домен Bot API: **`platform-api2.max.ru`** (не `platform-api.max.ru`),
   нужен сертификат Минцифры в доверенных на сервере.
4. Кнопка `open_app` в сообщении бота открывает мини-приложение — так
   воркер опроса (T-12) ведёт пользователя обратно в апп.
5. `auth_date` — unix-секунды; MAX рекомендует считать initData
   невалидной спустя **1 час**.
6. Диплинк мини-аппа: `https://max.ru/<botName>?startapp=<payload>`,
   payload до 512 символов `[A-Za-z0-9_-]` — основа рефералки (фича 3).
