# Spec: Парсинг резюме из PDF

Тикеты: T-29 (бек), T-30 (фронт). Фича: юзер загружает PDF-резюме → текст
извлекается в браузере → AI структурирует в наши поля → юзер правит и
подтверждает.

## Архитектура (решение)

| Этап | Где | Чем |
|------|-----|-----|
| Извлечение текста из PDF | фронт, `pdfjs-dist` (ленивый импорт) | текстовый слой PDF; кириллица извлекается надёжно |
| Структурирование в поля | бек, GLM через z.ai (`internal/scoring/ai.go`) | промпт с нашей JSON-схемой |
| Черновик в БД | `resumes` (source='file_parse', is_active=false) | до явного сохранения юзером |

Почему не Go-парсер PDF: кириллические PDF — минное поле (кодировки,
шрифты); pdfjs в браузере надёжен и не грузит сервер; файл целиком не
хранится (только извлечённый текст — по согласию юзера).

## Контракт

### POST /api/v1/my/resume/parse (Bearer, кандидат)

Запрос:
```json
{ "text": "Иван Петров — Backend-разработчик...", "source_name": "resume.pdf" }
```

- `text` — извлечённый текст, 50..30 000 символов (иначе 400).
- Бек: GLM структурирует → валидация (enum'ы, клампы, свап min/max) →
  upsert черновика (`source='file_parse'`, `source_text=<текст>`,
  `is_active=false` для нового / прежний `is_active` при обновлении).
- Ответ 200: `{ "resume": {...Resume...}, "ai_comment": "..." }`.
- AI недоступен → 200, поля пустые кроме `source_text`, `ai_comment`
  поясняет; юзер заполняет вручную.

### PUT /my/resume — как было (T-06), но:

- после parse сохраняет отредактированные поля, НЕ затирая `source_text`
  (уже реализовано);
- юзер явно подтверждает активность.

## AI-промпт (скелет, internal/scoring/ai.go)

Система: «HR-парсер. Верни СТРОГО валидный JSON без markdown по схеме…»
Пользователь: текст резюме. Нормализация после парсинга:

- `work_format`: словарь синонимов («удалённо», «удалёнка», «дистанционно» →
  remote; «гибрид» → hybrid; «офис» → onsite; неизвестное → onsite)
- `employment_type`: («полный день», «полная» → full_time; «частичная» →
  part_time; «контракт», «договор» → contract; «стажировка» → internship;
  неизвестное → full_time)
- `experience_months`: 0..600
- зарплата: int ≥ 0, min>max → свап

## Критерии приёмки

- [ ] Реальный текст СПб Go-резюме → черновик с ≥5 заполненными полями.
- [ ] Скан без текста → 200 + пустые поля + source_text + notes.
- [ ] Черновик неактивен, после PUT юзера — активен.
- [ ] AI-сбой не ломает ручку (200 + notes).
